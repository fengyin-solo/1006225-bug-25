# 水电站机组运行检修管理平台

面向电站台账、机组运行、调速励磁、主变与闸门、大坝渗流位移监测、机组检修与发电计划的一体化水电站运行检修管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `hydropower-plant-om:entries` 这一项，或调用 `resetModule(模块)`。

## 位移监测（独立领域层）

位移模块（`src/data/displacement/`）与通用扁平模块不同：**测点档案与观测测次分开存储**，
列表、超限清单、暂不可判定清单、缺项清单、导出 CSV 全部读取同一个计算引擎
（`engine.ts → buildOverview`），保证报表与明细始终一致。

- **缺测留空不当 0**：缺测是显式状态（`observed=false`、水平/垂直位移为 `null`、必填缺测原因）。
  累计位移只累加有效测次（以该测点首个有效测次为基准，重算合位移 `√(Δh²+Δv²)`），缺测跳过。
- **超限判定跳过缺测**：一次有效观测都没有 → 「空态」；最近一测次缺测 → 「观测中断」；
  允许位移缺失 → 「字段缺失」。这三类全部进「暂不可判定」，绝不混进超限，也不亮超限标记。
- **提交先整套校验、再查重、最后加锁落盘**：指纹重复或 `(测点, 业务日期)` 重复则整笔退回，
  以最先入库的一稿为准；模块级写入锁保证并发提交只让第一笔生效，同一测点不会把累计加两遍。
- **动作结果落到缺陷清单**：判定为超限的测点幂等写入「缺陷处置」模块（同一测点只留一条），
  缺陷处置菜单即另一个入口。
- **存量数据迁移**（首次进入位移模块时自动执行，键 `hydropower-plant-om:displacement-v2`）：
  - 按「测点编号」合并测点、按观测日期把多行排成测次序列；旧行自带的累计位移作废、统一重算；
  - 「早期缺测写成 0」的识别规则：首测（及首测前连续 0）视为真实基准保留；测点一旦出现过非零
    有效观测，其后的**全 0 测次**判为缺测误录，转缺测并注明「存量0值识别为缺测」，需外业核实补数；
  - 解析不成数值的文本按字段缺失单列；没有观测日期的旧行**不臆造日期**，测次日期留空、不进序列，
    在缺项清单挂「观测日期」，按业务日期补数后才计入。
- 领域规则的端到端断言在 `frontend/scripts/verify-displacement.mjs`，运行 `npm run verify`。
- 重置位移示例数据：清掉 `hydropower-plant-om:displacement-v2` 后刷新；保留存量重迁可删 v2 键后
  再进入页面。
